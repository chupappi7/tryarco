# tryarco.app

ARCO's website: the landing page, privacy policy, terms, support, guides and press pages, and `connect.html`, which passes Apple's iCloud sign-in on to `arco login` (see arco-mcp).

The TikTok slide images stay on `chupappi7/arco-app` (chupappi7.github.io/arco-app), because TikTok's domain verification is tied to that address.
